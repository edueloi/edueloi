### 👨‍💻 Sobre Mim

Sou um Engenheiro de Software com sólida experiência no desenvolvimento e manutenção de aplicações web escaláveis. Atualmente, como **Engenheiro de Software Pleno** na **Comexport**, integro o **Clients Squad**, onde foco em entregar produtos de alta qualidade para clientes internos e externos. Minha paixão é aprender continuamente e aplicar as mais recentes tecnologias para criar interfaces modernas e responsivas.

- 🔭 Atualmente trabalhando na **criação e manutenção de aplicações baseadas em microserviços**.
- 🎓 Cursando **MBA em Engenharia de Software na USP/Esalq** para aprimorar minhas habilidades estratégicas.
- 🌱 Explorando constantemente o universo da **Inteligência Artificial** e automação com ferramentas como **Copilot**.
- 🚀 Focado em performance, clean code e na melhor experiência do usuário.
